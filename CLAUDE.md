This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

One-page French showcase site for an occupational therapist / IBCLC lactation consultant (https://ergotherapeute-lyon.fr). Next.js 16 (App Router) + React 19, Tailwind 3 + Sass, content in Prismic, hosted on Netlify. Site copy is in French. Node 22 (`.nvmrc`).

## Commands

```bash
npm run dev            # http://localhost:3000
npm run build          # prebuild wipes .next/cache/fetch-cache first
npm run lint           # ESLint
npm run slicemachine   # Slice Machine UI on :9999, to edit/push the Prismic model
```

There is no test suite. Maps need `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` in `.env.local`; the revalidate webhook needs `PRISMIC_WEBHOOK_SECRET` (set on Netlify).

## Architecture

- **Single Prismic document.** All text, images and prices live in one `homepage` singleton (model: `customtypes/homepage/index.json`, one tab per section). `src/app/data/homepage.ts` exposes `getHomepage()` wrapped in React `cache()` so `generateMetadata`, the page and `opengraph-image.tsx` share one request. `prismicio-types.d.ts` is generated by Slice Machine — don't hand-edit; after changing the model, push it via Slice Machine so the types regenerate.
- **No slices, no draft previews.** `src/slices/index.ts` is empty (generated) and `/slice-simulator` is Slice Machine boilerplate. Only published content is read; do not reintroduce Prismic preview/toolbar code (removed on purpose).
- **Page composition.** `src/app/page.tsx` fetches the document once and passes `data` as a prop to each section component in `src/app/components/*` (Header, Ergotherapy, IBCLC, Consultation, About, Appointment, Funding, StructuredData). Sections are presentational; fallbacks for empty SEO fields come from `src/app/data/practice.ts`, which also holds shared helpers (`formatAddress`, `toInternationalPhone`) and the `Location` type derived from the Prismic types.
- **Caching/refresh.** `src/prismicio.ts` `createClient` tags production fetches `prismic` with `revalidate: 60`; the Prismic publish webhook POSTs to `src/app/api/revalidate/route.ts` (checks `PRISMIC_WEBHOOK_SECRET`, then `revalidateTag("prismic", { expire: 0 })`). The 60s expiry is the fallback if the webhook fails.
- **Still hardcoded in code:** navigation links (`components/Navigation/index.jsx`), decorative icons (`public/images/icones/`), colors/layout (`tailwind.config.ts`, `globals.scss`).
- **SEO** is generated by Next: `robots.ts`, `sitemap.ts`, `opengraph-image.tsx`, metadata in `layout.tsx`/`page.tsx`, JSON-LD in `components/StructuredData`.
- **Headers.** Security headers are in `next.config.mjs`; `netlify.toml` only sets cache headers for `public/images/*` because Next's `headers()` doesn't apply to files Netlify serves from `public/`. `inlineCss` is enabled on purpose (avoids render-blocking CSS).
- `scripts/prismic-migrate-homepage.mjs` is a one-off migration that refuses to run if a homepage is already published.

## Deployment

PRs get Netlify Deploy Previews (noindex); merging to `main` deploys to production.
